## 🎯 **HOW TO USE THE WEBSITE:**

### **Browse Products:**
1. Open http://localhost:3000
2. See all products on home page
3. Click category buttons to filter
4. Use search bar to find products

### **Add to Cart:**
1. Click "Add to Cart" on any product
2. Click cart icon (top right) to view cart
3. Update quantities with +/- buttons
4. Remove items if needed

### **Checkout:**
1. Click "Proceed to Checkout" in cart
2. Fill shipping information:
   - Full Name
   - Phone Number
   - Delivery Address
   - City
   - PIN Code
3. Select payment method:
   - Google Pay (GPay)
   - Cash on Delivery (COD)
4. Click "Place Order"
5. See order confirmation!
